2019년 제7회 K-Hackathon VR&AR 앱 개발 챌린지에 출품한 Leeds Multi-Tap(멀티탭의 황금기) 기록이다. 주제는 클라우드 서비스 기반의 전기 절약을 위한 Wi-Fi 스마트 멀티탭 개발이었다. 같은 줄기의 하드웨어·클라우드·앱 구성은 포스터(IoT Smart Plug Based on Cloud Services)와 2022-04-07 발표 자료 구름 스마트 플러그(Team U.S)에도 정리돼 있다.

배경과 차별점

일상에서 빼놓기 어려운 멀티탭에 Arduino를 붙여, Wi-Fi(데이터) 기반 IoT 스마트 멀티탭을 만들었다. 당시 국내에는 Bluetooth 기반 멀티탭이 많았고, Wi-Fi를 쓰는 제품은 대기업 유통·통신사 홈매니저 가입을 전제로 월 정액을 요구하는 경우가 많았다.

결선 소개 자료 기준으로 기능은 타 제품과 비슷하게 맞추되, 아래를 차별점으로 잡았다.

  • Wi-Fi를 쓰는 사용자라면 월 정액 없이 쓸 수 있다.
  • 통신 모듈·개인 서버 쪽으로 단가를 낮춰 가격 부담을 줄인다.
  • 핸드폰만 있으면 어디서든 쓸 수 있는 시장성을 노린다.

포스터·발표 자료에서는 같은 방향을 “홈매니저 구독이 필요하지 않음”, “클라우드 웹 서비스 제공”으로도 적어 두었다.

핵심 기능

결선 서비스 소개 자료의 세 축은 다음과 같다.

  1. 원격 ON/OFF — Wi-Fi로 언제 어디서든 전원을 켠다·끈다.
  2. 개별 구 제어 — 원하는 콘센트만 골라 제어한다.
  3. 전력량 측정·시각화 — 전류를 재고 사용자가 인지할 수 있게 보여 준다.

포스터·구름 스마트 플러그 자료에는 여기에 예약, 데이터 모니터링(온도·습도·전력), GPS, Push 알림이 이어서 적혀 있다. ThingSpeak Cloud API Key와 Blynk Cloud Token을 Arduino 쪽에서 묶어 멀티 클라우드로 쓰는 구성이다.

  • ThingSpeak — 센서 데이터(온도·습도·전력 등) 저장, MATLAB 연동 분석·시각화, Excel export, 특정 이벤트 trigger
  • Blynk — iOS/Android 앱 UI로 Arduino·유사 보드를 인터넷으로 제어

타깃·마케팅·기대 효과

구분 내용
타깃 일상에서 누구나 쓰는 만큼 전연령층
마케팅 SNS·홍보 영상, 시제품 길거리 시연
비용 개인 서버·NodeMCU/WeMos·통신 모듈 단가로 가격 부담 완화
전력 원격 제어·측정으로 전기 낭비를 줄임

발표 자료의 적용 방안에는 1인 가구·독거노인 가구를 공공기관용 클라우드로 모니터링하고, 이상 반응 시 알림을 보내는 흐름도 적혀 있다.

하드웨어와 시제품

발표 자료(2022-04-07) 기준 구성은 WeMos D1R1(ESP8266), ACS712, Relay, DHT11, GPS 모듈이다. 해커톤 쪽 기록에는 Arduino Uno·NodeMCU(ESP8266)·ACS712도 함께 적혀 있다.

시스템 구성과 클라우드 흐름

전체 구성은 모듈(센서·릴레이·WeMos) → Wi-Fi 공유기 → ThingSpeak / Blynk → 웹·모바일 UI → 사용자다. ThingSpeak 쪽은 MATLAB 분석·Excel export, Blynk 쪽은 ON/OFF·Timer·Data·GPS UI를 맡는다.

포스터의 시퀀스는 MQTT로 상태를 올리고 클라우드에서 제어한 뒤, 바뀐 상태를 다시 올리는 흐름이다. 문제 발생 시 Push 알림도 적어 두었다.

클라우드 서버 단계는 발표 자료에 여덟 단계로 적혀 있다.

  1. 외부 라이브러리로 모듈에서 데이터 측정
  2. ESP8266이 Wi-Fi 공유기 IP를 받아 연결
  3. ThingSpeak로 데이터 전송
  4. Blynk로 데이터 전송
  5. 클라이언트가 동작 요청
  6. ThingSpeak 상태 정보를 UI로 전송
  7. Blynk 상태 정보를 UI로 전송
  8. UI에서 데이터 시각화

모바일 앱(Blynk) 쪽에는 예약, Push 알림, GPS, 실시간 모니터링(온도·전력량), 원격 제어 화면이 정리돼 있다.
