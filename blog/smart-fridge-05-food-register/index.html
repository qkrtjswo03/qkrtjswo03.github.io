바코드로 찾은 식품이든, 손으로 넣는 식품이든 마지막에는 이름·유통기한·분류·이미지를 서버에 남겨야 한다. 이 글은 등록 화면 쪽이다.

유통기한 달력

Calendar / GregorianCalendar로 오늘 날짜를 받아 TextView에 보여 주고, DatePicker로 고른 값으로 갱신한다.

Calendar cal = new GregorianCalendar();
int year = cal.get(Calendar.YEAR);
int month = cal.get(Calendar.MONTH);
int day = cal.get(Calendar.DAY_OF_MONTH);

void updateNow() {
  foodDateTxt.setText(String.format("%d/%d/%d", year, month + 1, day));
}

카메라·앨범 이미지

Manifest에 카메라·저장소 권한을 넣고, TedPermission 등으로 런타임 허용을 받는다.

<uses-permission android:name="android.permission.CAMERA" />
<uses-permission android:name="android.permission.READ_EXTERNAL_STORAGE" />
<uses-permission android:name="android.permission.WRITE_EXTERNAL_STORAGE" />

앨범은 Intent.ACTION_PICK, 촬영은 MediaStore.ACTION_IMAGE_CAPTURE에 임시 파일 Uri를 넘긴다. 촬영 파일은 앱 전용 폴더에 timestamp 이름으로 만든다.

URL 이미지를 Bitmap으로

바코드 조회 결과의 foodImage는 URL이다. APK에 이미지를 모두 넣지 않으려고 서버(또는 CDN) URL을 쓰고, 백그라운드 스레드에서 Bitmap으로 디코드한 뒤 ImageView에 붙인다.

Thread thread = new Thread(() -> {
  try {
    URL url = new URL(foodImageUrl);
    HttpURLConnection conn = (HttpURLConnection) url.openConnection();
    conn.setDoInput(true);
    conn.connect();
    InputStream is = conn.getInputStream();
    bitmap = BitmapFactory.decodeStream(is);
  } catch (IOException e) {
    e.printStackTrace();
  }
});
thread.start();
thread.join();
foodImageView.setImageBitmap(bitmap);

빈칸 검증 후 서버 저장

등록 버튼에서 이름·날짜·분류·냉장/냉동 구분이 비면 Dialog로 막고, 통과하면 Volley StringRequest로 PHP에 POST한다.

if (foodName.isEmpty() || foodDate.isEmpty()
    || category.equals("-- 선택하세요 --") || division.isEmpty()) {
  new AlertDialog.Builder(this)
      .setMessage("빈칸이 있습니다.")
      .setNegativeButton("확인", null)
      .show();
  return;
}

FoodInsertRequest request = new FoodInsertRequest(
    foodName, foodDate, division, category, foodImage, email, listener);
Volley.newRequestQueue(this).add(request);

서버 FoodInsert.php는 prepared statement로 Refrigerator 테이블에 insert한 뒤 { "success": true }를 돌려준다. DB 접속 정보는 placeholder다.

<?php
$con = mysqli_connect("<DB_HOST>", "<DB_USER>", "<DB_PASSWORD>", "<DB_NAME>");
mysqli_set_charset($con, "utf8");

$foodName  = $_POST["foodName"];
$foodDate  = $_POST["foodDate"];
$division  = $_POST["division"];
$category  = $_POST["category"];
$foodImage = $_POST["foodImage"];
$email     = $_POST["email"];

$stmt = mysqli_prepare(
  $con,
  "INSERT INTO Refrigerator (foodName, foodDate, division, category, foodImage, email) VALUES (?,?,?,?,?,?)"
);
mysqli_stmt_bind_param($stmt, "ssssss", $foodName, $foodDate, $division, $category, $foodImage, $email);
mysqli_stmt_execute($stmt);

echo json_encode(array("success" => true));
?>

성공하면 메인 화면으로 돌아가 목록을 다시 본다.
