스캔으로 얻은 바코드만으로는 화면에 이름이 안 뜬다. 서버 MySQL의 barcode 테이블을 조회해 이름·유통기한·분류·이미지 URL을 가져온다.

2편에서 ZXing으로 읽은 바코드 문자열은 GlobalApplication에 담아 둔다. 이 편에서는 그 값으로 서버 목록을 조회해 이름·유통기한·분류를 화면에 채운다. 이미지 URL을 Bitmap으로 띄우는 과정은 5편에서 다룬다.

당시 서버는 DotHome 공유 호스팅(Apache + PHP + MySQL)에 올렸다.

barcode 테이블에는 바코드 번호·식품 이름·유통기한·분류·이미지 URL이 들어 있다. 이미지 컬럼은 공개 CDN URL을 썼다.

서버: barcode.php

공유 호스팅에서 PHP가 MySQL에 붙어 전체 바코드 목록을 JSON으로 내려준다. 접속 정보는 placeholder로 둔다.

<?php
$con = mysqli_connect("<DB_HOST>", "<DB_USER>", "<DB_PASSWORD>", "<DB_NAME>");
mysqli_set_charset($con, "utf8");

$result = mysqli_query($con, "SELECT * FROM barcode");
$response = array();

while ($row = mysqli_fetch_array($result)) {
  array_push($response, array(
    "barcodeNum"   => $row[0],
    "foodName"     => $row[1],
    "foodDate"     => $row[2],
    "foodCategory" => $row[3],
    "foodImage"    => $row[4]
  ));
}

echo json_encode(array("response" => $response));
mysqli_close($con);
?>

mysqli_set_charset을 utf8로 두어 한글 이름·분류가 깨지지 않게 한다. SELECT * FROM barcode로 행을 모두 읽은 뒤, 컬럼 순서대로 barcodeNum, foodName, foodDate, foodCategory, foodImage 키를 붙여 response 배열로 묶어 json_encode한다.

응답 형태는 대략 다음과 같다.

{
  "response": [
    {
      "barcodeNum": "8801234567890",
      "foodName": "우유",
      "foodDate": "2019/10/20",
      "foodCategory": "유제품",
      "foodImage": "https://<IMAGE_HOST>/milk.png"
    }
  ]
}

예시는 응답 배열 한 건의 모양이다. 키 이름은 위 PHP가 붙인 것과 같다. 실제 접속 주소와 이미지 호스트는 placeholder다.

클라이언트: AsyncTask로 GET

메인 스레드에서 네트워크를 치지 않도록 AsyncTask로 URL을 연다.

class BackgroundTask extends AsyncTask<Void, Void, String> {
  String target;

  @Override
  protected void onPreExecute() {
    target = "<SERVER_URL>/barcode.php";
  }

  @Override
  protected String doInBackground(Void... voids) {
    try {
      URL url = new URL(target);
      HttpURLConnection conn = (HttpURLConnection) url.openConnection();
      InputStream in = conn.getInputStream();
      BufferedReader reader = new BufferedReader(new InputStreamReader(in));
      StringBuilder sb = new StringBuilder();
      String line;
      while ((line = reader.readLine()) != null) {
        sb.append(line).append("\n");
      }
      reader.close();
      in.close();
      conn.disconnect();
      return sb.toString().trim();
    } catch (Exception e) {
      e.printStackTrace();
      return null;
    }
  }
}

onPreExecute에서 요청 주소를 <SERVER_URL>/barcode.php로 두고, doInBackground에서 HttpURLConnection으로 연결한 뒤 응답 본문을 문자열로 모은다. 예외가 나면 이 메서드는 null을 반환한다.

JSON 파싱 후 스캔 값과 비교

onPostExecute에서 배열을 돌며 GlobalApplication에 넣어 둔 바코드와 barcodeNum이 같은 행을 고른다.

JSONObject jsonObject = new JSONObject(result);
JSONArray jsonArray = jsonObject.getJSONArray("response");
GlobalApplication app = (GlobalApplication) getApplication();
String scanned = app.getBarcode();

for (int i = 0; i < jsonArray.length(); i++) {
  JSONObject row = jsonArray.getJSONObject(i);
  if (row.getString("barcodeNum").equals(scanned)) {
    barcodeNumTxt.setText(row.getString("barcodeNum"));
    foodNameTxt.setText(row.getString("foodName"));
    foodDateTxt.setText(row.getString("foodDate"));
    categoryTxt.setText(row.getString("foodCategory"));
    // foodImage URL → Bitmap 로딩은 5편에서
    break;
  }
}

response 배열을 돌다가 barcodeNum이 스캔 값과 같은 행을 찾으면 바코드·이름·유통기한·분류 TextView를 채우고 반복을 끝낸다. foodImage는 주석대로 5편에서 URL을 Bitmap으로 불러 쓴다. 일치하는 행이 없으면 이 코드는 TextView를 바꾸지 않는다.

정리

쪽 역할
MySQL barcode 바코드 → 식품 메타데이터
PHP SELECT 결과를 JSON으로 응답
AsyncTask 백그라운드 HTTP
onPostExecute 스캔 값과 매칭해 UI 채움

당시에는 목록 전체를 받아 클라이언트에서 비교했다. 지금은 쿼리 파라미터로 한 건만 조회하는 편이 낫다.

이 단계에서 보면 되는 것은 다음과 같다.

  • PHP가 response 배열과 다섯 키를 내려주는지
  • AsyncTask가 메인 스레드가 아닌 곳에서 응답 문자열을 받아 오는지
  • 스캔 값과 같은 barcodeNum을 찾아 이름·유통기한·분류가 채워지는지

안 될 때 확인할 곳:

  • doInBackground가 null을 반환하지 않았는지 본다.
  • JSON의 response 배열과 키 이름이 PHP와 같은지 본다.
  • GlobalApplication에 담긴 스캔 값이 테이블의 barcodeNum과 같은지 본다.

여기까지 되면 스캔한 바코드에 이름·유통기한·분류가 붙는 것이다.
