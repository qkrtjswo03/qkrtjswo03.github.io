잠긴 글입니다. 저장소 주인만 본문을 볼 수 있습니다.

냉장고 데이터는 사용자별로 나뉘어야 해서 Kakao 계정 로그인을 붙였다. Kakao Developers에서 앱을 만들고, Native 앱 키·키 해시·패키지명을 등록한 뒤 SDK를 프로젝트에 넣는다.

Developers 콘솔 설정

앱 만들기 → 키 발급 → 사용자 관리 활성화 → Android 플랫폼·패키지·키 해시 등록 순이다. 키 값은 원본에서도 가려 두었고, 여기에도 넣지 않는다.

Gradle과 앱 키

gradle.properties에 SDK 좌표를 두고, 모듈 dependencies에 usermgmt를 추가한다.

KAKAO_SDK_GROUP=com.kakao.sdk
KAKAO_SDK_VERSION=1.1.7
<!-- res/values/strings.xml -->
<string name="kakao_app_key"><KAKAO_APP_KEY></string>

Manifest application에 메타데이터를 넣는다.

<meta-data
  android:name="com.kakao.sdk.AppKey"
  android:value="@string/kakao_app_key" />

키 해시는 서명 인증서를 SHA-1 → Base64로 만들어 Developers 콘솔에 등록한다. 실제 키 값은 글에 적지 않는다.

GlobalApplication에서 SDK 초기화

앱 전역에서 한 번만 KakaoSDK.init을 호출한다.

public class GlobalApplication extends Application {
  private static volatile GlobalApplication instance;

  @Override
  public void onCreate() {
    super.onCreate();
    instance = this;
    KakaoSDK.init(new KakaoSDKAdapter());
  }

  public static GlobalApplication getGlobalApplicationContext() {
    return instance;
  }
}

Manifest의 android:name을 .GlobalApplication으로 지정한다.

KakaoSDKAdapter

세션 옵션과 Application Context를 SDK에 넘긴다. 로그인 타입은 KAKAO_LOGIN_ALL로 두어 톡·계정 웹뷰를 모두 허용했다.

public class KakaoSDKAdapter extends KakaoAdapter {
  @Override
  public ISessionConfig getSessionConfig() {
    return new ISessionConfig() {
      @Override
      public AuthType[] getAuthTypes() {
        return new AuthType[] { AuthType.KAKAO_LOGIN_ALL };
      }
      // 나머지 옵션은 기본값 사용
    };
  }

  @Override
  public IApplicationConfig getApplicationConfig() {
    return () -> GlobalApplication.getGlobalApplicationContext();
  }
}

로그인 버튼과 SessionCallback

레이아웃에는 Kakao가 제공하는 LoginButton을 쓰거나, 커스텀 버튼이 Session.open을 호출하게 한다.

public class SessionCallback implements ISessionCallback {
  @Override
  public void onSessionOpened() {
    requestMe(); // Access Token 발급 성공 → 프로필 요청
  }

  @Override
  public void onSessionOpenFailed(KakaoException exception) {
    Log.e("SessionCallback", exception.getMessage());
  }

  private void requestMe() {
    UserManagement.requestMe(new MeResponseCallback() {
      @Override
      public void onSuccess(UserProfile userProfile) {
        // 이메일 등 허용된 항목만 GlobalApplication에 보관
      }
      @Override public void onSessionClosed(ErrorResult errorResult) { }
      @Override public void onNotSignedUp() { }
    });
  }
}

로그아웃은 UserManagement.requestLogout 후 로그인 화면으로 되돌린다.
