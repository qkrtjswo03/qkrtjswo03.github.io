ZXing IntentIntegrator로 카메라를 열어 바코드를 읽고, 결과를 GlobalApplication에 담아 다음 화면으로 넘기는 흐름을 정리한다.

잠긴 글입니다. 저장소 주인만 본문을 볼 수 있습니다.

식품을 손으로만 치면 오타와 누락이 생긴다. 그래서 ZXing으로 바코드를 스캔해 서버에 있는 식품 정보와 맞추는 쪽으로 잡았다.

전시·데모용으로 준비한 바코드 시트다. 라면·우유·과자 등 제품 사진 아래에 실제 바코드를 붙여 스캔을 보여 주었다.

권한과 Activity 등록

카메라가 필요하므로 Manifest에 CAMERA 권한을 넣고, ZXing 캡처 Activity를 등록한다.

<uses-permission android:name="android.permission.CAMERA" />

<activity
  android:name=".qr.CaptureActivityAnyOrientation"
  android:screenOrientation="fullSensor"
  android:stateNotNeeded="true"
  android:theme="@style/zxing_CaptureTheme"
  android:windowSoftInputMode="stateAlwaysHidden" />

런타임 권한이 필요한 OS에서는 checkSelfPermission → 거부된 적 있으면 안내 Dialog → requestPermissions 순으로 요청한다. 허용되지 않으면 스캔을 진행하지 않는다.

스캔 시작

메인 화면의 FloatingActionButton에서 스캔 결과 Activity로 이동한다. 결과 Activity의 onCreate에서 IntentIntegrator를 바로 연다.

IntentIntegrator integrator = new IntentIntegrator(this);
integrator.initiateScan(); // 바코드 스캔 카메라 실행

결과 받기

onActivityResult에서 IntentIntegrator.parseActivityResult로 값을 꺼낸다.

IntentResult result = IntentIntegrator.parseActivityResult(requestCode, resultCode, data);
if (result == null || result.getContents() == null) {
  return; // 사용자가 취소한 경우
}
String barcode = result.getContents();

GlobalApplication app = (GlobalApplication) getApplication();
app.setBarcode(barcode);

바코드 문자열은 Activity 경계를 넘어야 해서 **Application 싱글톤(GlobalApplication)**에 잠깐 올려 둔다. 다음 글에서 이 값으로 서버 JSON과 비교한다.

실제 등록·스캔 흐름 화면이다. 카메라 촬영, 바코드 스캔, 인식 결과 확인이 한 장에 있다.
